## Overview

The Badges system is a gamification feature that rewards users for achieving milestones. Badges are automatically awarded based on user activity such as writing reviews, borrowing books, and maintaining good standing.

**Route**: `/dashboard/my-badges`

## Viewing Your Badges

1. Navigate to **Dashboard** → **My Badges** (`/dashboard/my-badges`)
2. The page is split into two tabs:
   - **Badge Catalog** — all badges available in the system, with a lock or earned state on each badge
   - **My Badges** — only the badges you have already earned, including earned date, badge level, and criteria summary

Clicking any badge tile opens a detail drawer showing the badge name, its rarity level, description, exact criteria, and (for earned badges) the timestamp and context when it was awarded.

## Badge Categories

Badges are organized by category:

| Category | Description | Examples |
|----------|-------------|---------|
| Reviews | Earned by writing book reviews | First Review, Review Enthusiast, Seasoned Reviewer |
| Loans | Earned by borrowing books | First Loan, Prolific Reader |
| Approval | Earned for account milestones | Approved Member |
| Activity | Earned for platform engagement | Daily visitor streaks, reservation and wishlist badges |
| Penalties | Earned for good standing | No Penalties milestones and similar standing rewards |

## Badge Levels

Each badge has a level indicating its rarity:

| Level | Description |
|-------|-------------|
| Bronze | Common — easy to earn |
| Silver | Uncommon — moderate effort |
| Gold | Rare — significant achievement |
| Platinum | Legendary — exceptional dedication |

## How Badges Are Awarded

Badges are evaluated automatically by the system:

1. **Trigger events** — badge evaluators run when relevant actions occur (e.g., after submitting a review)
2. **Criteria check** — the evaluator checks if the user meets the badge criteria
3. **Automatic award** — if criteria are met, the badge is awarded and a notification is sent

<Aside type="note" title="Automatic Evaluation">
You don't need to do anything special to earn badges. Just use the system normally — write reviews, borrow books, and engage with the catalog. Badges are awarded the next time you are signed in after the trigger event.
</Aside>
