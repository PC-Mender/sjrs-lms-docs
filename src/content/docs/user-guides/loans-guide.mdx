## Overview

Use the Loans page to track books you've borrowed, their due dates, and the status of each request. Everything shown here is for your account only.

**Route**: `/dashboard/loans`

## Loan Statuses

Each loan appears with one of these statuses so you always know where your request stands:

| Status | Color | What it means for you |
|--------|-------|-----------------------|
| Pending | orange | Your request was submitted; library staff are reviewing it |
| Approved | green | Your request was approved — the book is ready for pickup |
| Active | cyan | Book is currently checked out to you |
| Overdue | red | The return date has passed. Return it promptly to stop additional charges. |
| Returned | blue | Book was returned successfully |
| Rejected | magenta | Your request was declined. Contact library staff if you have questions. |
| Cancelled | default | Request was cancelled (either by you or by staff) |

## Viewing Your Loans

1. Navigate to **Dashboard** → **Loans** (`/dashboard/loans`)
2. You'll see a table listing all your loans with these columns:
   - **Book** — title, copy number, and author
   - **Status** — current loan state (see the table above)
   - **Borrowed On** — date the book was issued to you
   - **Due Date** — the date the book is expected back
   - **Renewal** — shows whether an extension has been requested, rejected, or how many times the loan has been extended
   - **Returned On** — date the book was returned (if applicable)
   - **Actions** — buttons available for this loan (e.g., Cancel, Request Extension)
3. Use the **status filter** dropdown to narrow the list (e.g., show only "Active" or "Overdue" items)
4. Use the **date range picker** to filter by borrowed date
5. Use the **search bar** to find loans by book title or status

## Requesting a Loan

Books are requested from the Catalog and submitted as orders that library staff then review:

1. Go to **Dashboard** → **Catalog** (`/dashboard/catalog`)
2. Find the book you want to borrow
3. Click the book card to open its details
4. Click **Add to Request Cart** for any available copy
5. Open the **Request Cart** and click **Submit**
6. Track the progress in **Dashboard** → **Orders**
7. Once approved by staff, the loan appears on the Loans page

<Aside type="note" title="Borrow Quota">
A quota indicator is shown in the catalog telling you how many borrow slots remain. Active loans, overdue loans, and pending requests all count toward your total quota.
</Aside>

<Aside type="caution" title="Overdue Items Prevent New Requests">
If any of your books are overdue, you won't be able to place new borrow requests until those items are returned and any outstanding penalties are resolved.
</Aside>

## Requesting a Loan Extension

If you need more time with a book, you can submit an extension request for staff approval:

1. Go to **Dashboard** → **Loans**
2. Look for an Active loan whose due date is within the next 3 days
3. Click the **Request Extension** button (circular reload icon) next to the loan
4. Confirm the request in the dialog
5. The Renewal column will show "Requested" until staff decide

<Aside type="caution" title="Extension Window">
Requests are only accepted within 3 days of the due date, and only before the loan becomes overdue. You cannot request an extension once a loan is returned, cancelled, rejected, or already past the due date.
</Aside>

<Aside type="caution" title="Extension May Not Be Available">
An extension request may not be offered or may be denied when:
- Another user has already reserved this book
- You have reached the maximum number of extensions allowed for your type of account
- An extension request is already waiting on this loan
- You are currently signed in with a staff role — switch to your borrower (patron) role to request extensions
</Aside>
