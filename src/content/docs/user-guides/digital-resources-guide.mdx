## Overview

Digital Resources include e-books, online articles, PDFs, and other digital materials available through the library. Unlike physical books, most digital resources can be read directly in the browser without borrowing, or downloaded when the resource publisher allows it.

**Route**: `/dashboard/digital-resources`

## Browsing Digital Resources

1. Navigate to **Dashboard** → **Digital Resources** (`/dashboard/digital-resources`)
2. Resources are displayed in a searchable table or card layout
3. Use the **search bar** to find resources by title, author, or keyword
4. Filter by **resource type** (e-book, PDF, web link, audio book, etc.)

## Viewing a Digital Resource

1. Click on any resource to open the detail view
2. The detail page shows:
   - Title, author, and description
   - Resource type and format
   - Availability and access information
   - File size (for downloadable resources)
3. Click **Read Now** to open the resource in the built-in reader
4. Or click **Download** if downloading is permitted for that resource

## Reading Digital Books & PDFs

The built-in digital book reader supports:

- **Page navigation** — flip through pages with next/previous buttons
- **Zoom controls** — adjust the page scale for readability
- **Read session tracking** — progress and reading time are recorded automatically

Your reading progress is tracked automatically. Return to any digital book and it will resume from where you left off.

**Reader route**: `/dashboard/digital-resources/read/:id`

## Download Sources

A digital resource can have more than one source so readers always have a working link:

- **Direct file uploads** — files uploaded and hosted by the library
- **External URLs** — links to the publisher site, open-access repositories, or third-party digital libraries
- **Priority order** — sources are ranked so the most reliable link is tried first
