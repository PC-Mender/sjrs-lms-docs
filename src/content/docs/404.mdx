## Overview

This documentation site displays a 404 page when a visitor navigates to a URL that doesn't correspond to any published page. The 404 page is built into [Astro Starlight](https://starlight.astro.build/) and automatically inherits the site's theme, navigation sidebar, and search bar.

## How It Works

Starlight generates a static `404.html` page at build time. When a visitor hits a non-existent URL:

1. **Cloudflare Workers** serves `404.html` with a `404` status code
2. The page renders within the standard Starlight layout (sidebar, header, footer)
3. Visitors can use the search bar or sidebar to find the content they need

## Features

- **Consistent Layout**: Uses the same Starlight layout as all other docs pages
- **Search Bar**: Visitors can search for the content they were looking for
- **Sidebar Navigation**: Full sidebar is available to browse docs sections
- **Themed**: Automatically adapts to light/dark mode

## Customization

The 404 page is generated by Starlight's built-in [404 route](https://github.com/withastro/starlight/blob/main/packages/starlight/routes/static/404.astro). To customize it:

1. **Override the component**: Add a custom `404.astro` component in `src/components/` and register it in `astro.config.mjs` under `components`
2. **Static assets**: Place a custom `404.html` in `public/` to bypass Starlight's default entirely
